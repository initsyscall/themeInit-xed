# themeInit

Deep purples and soothing colors for [Xed-Editor](https://github.com/Xed-Editor/Xed-Editor). Ships with a light and a dark variant.

## Install

From the [Xed store](https://xed-editor.app), or build from source:

```sh
git clone https://codeberg.org/initsyscall/themeInit-xed
cd themeInit-xed
node build.js
```

In Xed-Editor go to **Settings → Store → Install from storage** and pick
`output/com.initsyscall.themeinit_xed.xed`. Then select the theme under **Settings → Theme**.
